# REKLAM · Турецкий язык рекламы (3D)

Лексический гайд по теме «Реклама» на турецком в стиле F1-постера + платформа **Alterna Timur A0 → C1**.

- **3D (three.js):** болид в hero с летающими табличками (тап = перевод), 3D-ливрея (наклейки-слова прилетают на машину), 3D-карусель реальных экранов платформы, развевающийся клетчатый флаг
- 6 кругов: ливрея, вывески, ловушки, реклама в телефоне (Reklamı atla), пит-стоп грамматики, конструктор слогана
- Квалификация со стартовыми огнями, конфетти, tilt-карточки, озвучка tr-TR
- Mobile-first, без сборки. Без WebGL показывается 2D-версия
