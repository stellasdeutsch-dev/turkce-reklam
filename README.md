# REKLAM · Турецкий язык рекламы

Лексический гайд по теме «Реклама» на турецком в стиле F1-постера + платформа **Alterna Timur A0 → C1**.

- 6 кругов: ливрея болида (reklam, marka, sponsor…), уличные вывески (indirim, kampanya, 1 alana 1 bedava), ложные друзья, реклама в телефоне (Reklamı atla), пит-стоп грамматики, конструктор слогана
- Квалификация: 10 вопросов со стартовыми огнями
- Озвучка через Web Speech API (tr-TR)
- Честная реклама платформы: реальные записи экрана и скриншоты
- Mobile-first, без зависимостей и сборки
